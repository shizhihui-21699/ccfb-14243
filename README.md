# fraudmon — 话费欺诈实时监测

接收 PBX 的呼叫建立/挂断事件流,在呼叫建立时同步评分裁决(允许/拒绝),
在损失扩大前自动限制被盗用的分机。

## 运行

```sh
go run ./cmd/fraudmon
```

模拟 5 天(2026-11-19 周四 ~ 11-23 周一,含周末和 1 天节假日)的事件流,
叠加 4 种盗打手法,输出每种手法的发现时间、检出时损失、防护下总损失、
无防护对照损失和误限制统计。

## 结构

```
internal/core/   检测引擎(无依赖,可嵌入实时管道)
  types.go       事件、角色、限制级别、裁决
  risk.go        号码段风险表(最长前缀匹配,支持运营商动态更新)
  engine.go      多信号评分 + 限制/熔断
internal/sim/    流量与攻击模拟器、回放与统计
cmd/fraudmon/    场景编排与报告
```

## 检测信号(呼叫建立时评分,阈值 50 限国际 / 85 全限)

| 信号 | 分值 | 说明 |
|---|---|---|
| 目的地风险 | 45 × risk | 风险表 0..1,卫星电话 0.95、国内 0.02 |
| 呼叫转移/语音信箱回拨 | +25 | 非直拨路径呼出中高风险方向 |
| 非工作时间 | +15 | 夜间 23-06、周末、节假日(仅风险方向) |
| 分机此时段无呼叫习惯 | +10 | 分时段 EWMA 基线 |
| 超角色并发 | 18/路 | 员工 1、管理层 2、坐席 4;仅风险方向计入 |
| 10 分钟呼叫频率 | 15~40 | 员工 6、坐席 60、管理层 10 次/10min |
| 1 小时高风险话费 | +25 | 含在途呼叫实时累计,按角色阈值 |
| 同方向多分机集中呼叫 | +25 | ≥4 个分机 15 分钟内呼同一国家码(识别轮换) |

另有**全局熔断**:所有分机高风险话费合计(含在途)超过 400 元/滚动小时,
临时切断全局高风险方向 30 分钟(客服坐席豁免)。这是低慢速、分布式、
未评级号段三类"单分机看不出问题"攻击的最后防线。

限制 30 分钟自动解除,再次触发再次限制;被拦截的呼叫在建立阶段即拒绝,
不产生话费。

## 模拟的正常业务

- 员工:工作日白天 ~6 通/天,94% 国内,少量美/英/港长途;周末节假日骤减
- 出差员工 8 人:每天 ~2 通国际长途,时段延伸到早晚
- 管理层:国际通话偏多,晚间也有
- 客服中心 30 坐席:工作日 10-12、14-18 集中外呼,~10 通/坐席/小时
- 夜间少量值班电话;节假日整体话务 ~10%

## 模拟的盗打手法

1. **凌晨突发**:周六 02:00,3 个分机 30 路并发打卫星高价号
2. **低慢速**:工作时间 12 个分机轮换,每分机 ≤2 通/小时,全局并发 ≤3
3. **转移/回拨绕过**:呼叫转移到高价号(含单分机多路转移)+ 语音信箱回拨
4. **风险漂移**:攻击者使用运营商尚未评级的新号段,2 小时后风险表才更新

## 实测结果(种子固定,可复现)

| 场景 | 发现耗时 | 检出时损失 | 防护下损失 | 无防护损失 | 误限分机 |
|---|---|---|---|---|---|
| 基线(5 天含节假日) | - | - | - | - | 0 |
| 凌晨突发 | 0s(首通即拦截) | 0 | 0 | 205,754 | 0 |
| 低慢速轮换 | 10m30s | 126 | 262 | 9,407 | 0 |
| 转移/回拨 | 0s | 0 | 0 | 2,716 | 0 |
| 风险漂移 | 38m30s(早于风险表更新) | 405 | 1,262 | 6,088 | 0 |

低慢速场景有 4 次合法呼叫被全局熔断误拒(出差员工的国际长途撞上 30 分钟
熔断窗口)——这是熔断的固有代价,可通过给出差员工开白名单或缩短熔断窗口
进一步降低。

## 接入真实系统时

- `Engine.Process` 是纯函数式事件入口,直接挂到 CDR/AMI 事件流即可;
  呼叫建立事件需要在路由前同步拿到 `Decision`(预授权模式)。
- 阈值集中在 `EngineConfig`,按企业规模标定;`RiskTable.Set` 对接运营商
  费率表和安全情报的定时更新。
- 生产上还应有:限制动作的人工确认/解除通道、告警通知、以及把确认过的
  盗打样本回灌用于调阈值的闭环。
